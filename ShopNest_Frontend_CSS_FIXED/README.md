# ShopNest Modern Animated Frontend v3

Clean Vite + React frontend. Styling uses plain CSS; Tailwind is not required.

## Run

```powershell
npm install
npm run dev
```

Open the Local URL printed by Vite.

## Backend

Local Django:
`VITE_DJANGO_BASE_URL=http://127.0.0.1:8000`

For deployment, set `VITE_DJANGO_BASE_URL` to your deployed Django API URL.

The existing product, cart, checkout and API routes are preserved.
